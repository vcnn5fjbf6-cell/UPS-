# 身份证号查证件 Skill

## 功能说明

当用户想查询**自己**的证件信息时，必须先提供**身份证号**才能查询。查询内容包括：

- 高压电工证（是否有效、到期日期、应复审日期）
- 低压电工证（是否有效、到期日期、应复审日期）
- 制冷操作证（是否有效、到期日期、应复审日期）
- 登高证（是否有效、到期日期、应复审日期）
- 证书合规状态
- 缺少哪些证书
- 持证情况汇总
- 岗位类型与上岗要求

## 数据来源

飞书多维表格 **「（调整中）1. 全国在职运维人员证件信息（每日刷新）」**
- 总记录数: ~2657 人
- 数据每日刷新，由各区域/机房负责人维护
- 通过云端 API 服务访问，凭证不暴露给客户端

## 架构

```
用户对话 → Skill → id_cert_query.py → 阿里云 ECS 服务端 → 飞书 API
```

- **服务端**: 部署在阿里云 ECS（47.114.92.186:8765），持有飞书 API 凭证
- **客户端**: `id_cert_query.py`，仅负责接收身份证号、调用云端接口、格式化展示
- **安全**: API Key 验证 + 身份证号校验 + IP 限流（每分钟10次）

## 工作流程

### 步骤 1 — 要求用户提供身份证号

当用户触发查询时（例如"查我的证件""查我的证书"等），**必须先向用户索要身份证号**。对话示例：

> **用户**: 查一下我的证书
> **Agent**: 好的，查证件需要先核实身份。请输入你的**身份证号**（18位）

### 步骤 2 — 使用脚本查询

获取到身份证号后，调用查询脚本（自动连接云端 ECS 服务）：

```bash
python scripts/id_cert_query.py --id <18位身份证号>
```

### 步骤 3 — 返回查询结果

将脚本输出的结果呈现给用户，包括持证情况、各证书有效期、合规状态等。

### 查询参数

```bash
python scripts/id_cert_query.py --id <身份证号>
python scripts/id_cert_query.py --id <身份证号> --json         # JSON 输出
python scripts/id_cert_query.py --id <身份证号> --server <URL>  # 指定服务地址
python scripts/id_cert_query.py --id <身份证号> --key <KEY>     # 指定 API Key
```

| 参数 | 说明 | 必填 |
|------|------|:----:|
| `--id` | 18位身份证号（支持末位X/x） | ✅ |
| `--json` | JSON格式输出 | ❌ |
| `--server` | 服务地址（默认连接云端） | ❌ |
| `--key` | API Key（默认自动读取） | ❌ |

### 验证规则

- 必须是 **18 位**
- 前 17 位为数字
- 末位可以是数字或 X/x
- 含校验位验证

## 隐私说明

- 身份证号仅用于查询时传递，**不会被记录或存储**
- 查询结果中的身份证号默认做脱敏处理（仅显示前4位和后4位）
- 每次查询都是实时拉取，不会缓存个人数据
- 本 skill 仅限本人查询自己的证件信息，不可查询他人
- 飞书 API 凭证仅存储在云端环境变量中，不暴露给客户端

## 注意事项

1. **查询响应通常 3~8 秒**（Filter API 精确匹配，无需全量拉取）
2. 本系统仅管理**特种作业操作证**（高压/低压/制冷/登高），不包含学历、职称、技能等级证等
3. 如果查询不到，请确认身份证号是否输入正确
