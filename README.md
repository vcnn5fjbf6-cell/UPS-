# 华为 UPS 监控管理平台

这是一个静态版 UPS 管理监控系统，面向机房供配电和华为 UPS 运行监控场景。页面内置 UPS、变压器、ATS、母线、电池、旁路、负载连接关系和实时模拟数据，可直接用浏览器打开运行，也可以通过本地 Python 服务访问。

## 功能

- 账号登录访问，刷新或重新打开页面后必须重新登录
- 支持创建本地账号
- 默认管理员账号：`admin / admin123`
- 华为 UPS 实物运行状态展示
- UPS 实物阵列与架构实物 3D 展示
- 1# 至 10# 变压器连接走向展示
- 点击变压器按钮弹出对应走向
- 点击 UPS 后在运行状态栏展示对应 UPS 状态
- 断电检测、低电量检测和故障实时监控
- AI 巡检、巡检结论和巡检摘要导出
- 系统设置、阈值调整和恢复正常操作

## 运行方式

方式一：直接打开 `index.html` 即可运行。

```text
index.html
```

方式二：使用本地服务运行。

```bash
python3 server.py
```

然后访问：

```text
http://127.0.0.1:8000/index.html
```

无需安装第三方依赖。
